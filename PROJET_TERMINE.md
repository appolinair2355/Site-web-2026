## 🚀 Déploiement sur Render.com

### ÉTAPE 1: Préparer le dépôt Git
```bash
git init
git add .
git commit -m "Initial commit - Mont Sion Boutique"
git remote add origin https://github.com/YOUR_USERNAME/mont-sion-boutique.git
git push -u origin main
```

### ÉTAPE 2: Configuration Render.com

1. **Créer un compte** sur [Render.com](https://render.com)

2. **Nouveau Web Service** :
   - Connecter votre dépôt GitHub
   - Sélectionner le dépôt `mont-sion-boutique`

3. **Configuration** :
   - **Name**: `mont-sion-boutique`
   - **Environment**: Python 3
   - **Build Command**: (laisser vide)
   - **Start Command**: `python3 server.py`
   - **Port**: 10000 (défini dans server.py)

4. **Variables d'environnement** :
   - `PORT`: 10000

5. **Deploy** et attendre 2-3 minutes

### ÉTAPE 3: Accéder à votre site

Votre boutique sera accessible à l'URL fournie par Render, par exemple :
`https://mont-sion-boutique.onrender.com`
